# 🔐 Password Cracking with Networkwalks Tools

## 📌 Project Overview

This project is a cybersecurity laboratory exercise focused on understanding how password-protected PDF files can be tested in an **authorized lab environment** using browser-based security tools provided by Networkwalks.

The objective was to understand the basic workflow of:

**Protected PDF → Hash Extraction → Password Cracking → Password Recovery**

This exercise was completed strictly for **educational and authorized security testing purposes**.

---

## 🎯 Lab Objective

The objective of this lab was to recover the password of password-protected PDF files provided for the exercise by:

1. Uploading the protected PDF to the Networkwalks Hash Calculator.
2. Extracting the password hash.
3. Submitting the hash to the Networkwalks Password Cracker.
4. Recovering the password where possible.
5. Documenting the process and observations.

## 🔬 Lab Methodology

### Step 1 — Obtain the Lab Files

The password-protected PDF files were downloaded as part of the authorized Networkwalks laboratory exercise.

### Step 2 — Generate the Hash

The protected PDF was uploaded to the Networkwalks Hash Calculator.

The tool was used to obtain the hash associated with the protected file.

### Step 3 — Password Testing

The extracted hash was submitted to the Networkwalks Password Cracker.

The tool attempted to identify the password associated with the hash using its available password-cracking process.

### Step 4 — Document the Results

The results were recorded as part of the cybersecurity laboratory exercise.

Screenshots and observations can be added to this repository to demonstrate each stage of the process.

For this reason, this laboratory exercise was performed only against **files provided for the lab and files that I am authorized to test**.

```text
Password-Protected PDF
          │
```
